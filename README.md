# MANTA
MANTA: Moving-target Adaptive Network Transformation Architecture

## Start here

Each folder has starter code and a short list of learning resources:

- [Network](network/README.md): Mininet, Open vSwitch, and the Ryu controller.
- [Policy](policy/README.md): public IP/port mappings and rotation timing.
- [Experiments](experiments/README.md): traffic tests, scanning, and measurements.

First goal: make one fixed mapping work, then add rotation and compare results.
