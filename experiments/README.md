# Experiments

Test the shared network and save measurements.

## Where to start

1. [Mininet walkthrough](https://mininet.org/walkthrough/): start with ping and a simple web server/client test.
2. [iperf3 guide](https://software.es.net/iperf/invoking.html): measure throughput; use UDP tests for jitter/loss and JSON output to save results.
3. [Nmap reference](https://nmap.org/book/man.html): scan the lab service before and after rotation to compare what remains reachable.
4. [Ryu traffic monitor](https://book.ryu-sdn.org/en/html/traffic_monitor.html): collect switch flow/port counters alongside your traffic tests.
